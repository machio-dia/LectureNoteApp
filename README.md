# 家庭教師・授業専用 手書きノートアプリ (LectureNote v4.1)

Xiaomi Pad 7 と専用スタイラスペン向けのネイティブ Android ノートアプリです。

## タブレットへのインストール・更新
タブレットのブラウザで次のリンクを開くと、最新版の APK がダウンロードされます。開いてインストールすれば、ノートを残したまま上書き更新されます。

**https://github.com/machio-dia/LectureNoteApp/releases/latest/download/app-debug.apk**

（`main` ブランチに変更が入るたびに GitHub Actions が自動でビルドし、最新版として公開します。過去5回分は [Releases](https://github.com/machio-dia/LectureNoteApp/releases) に残ります）

## v4.1 の変更点
- **XY軸**: 先端の矢印をなくし、原点の位置を選べるように（ツールバーの「原点の位置」で9か所から選択。描いたあとも「選択」で囲み、オレンジの点をドラッグして移動可能）
- **目隠し（範囲指定）**: 上段の目隠しボタン →「範囲を選んで隠す」。ドラッグで好きな範囲を隠し、タップで開け閉め、開いた状態で右上の×をタップすると削除。ノートに保存され、スクロールや拡大にも追従する。PDFには出力しない
- **目隠し（全面）**: 同じボタン →「全面を隠す」でノート全体を一度に隠す。中央の「目隠しを外す」で戻る（下から隠すシートは廃止）
- **図形「四角に×」** を追加
- 保存形式は旧バージョンと互換（XY軸の原点位置はファイル末尾の追加情報として保存。旧版で開くと新しい図形は手書き線として表示される）

## v4.0 の変更点

### 画面デザインの全面見直し
- **編集画面を2段のバーに整理**
  - 上段: ホームへ戻る / ノート名（タップで変更）/ タイマー / 目隠しシート / 元に戻す・やり直す / ページ / 表示倍率 / 全画面 / その他メニュー
  - 下段: ツール（ペン・マーカー・図形・消しゴム・選択・ポインター）と、選んだツールの設定だけを表示
- ボタンはすべてアイコン＋ラベル、44dp 以上の押しやすい大きさに統一
- 削除などの危険な操作は「︙」メニューにまとめ、確認ダイアログを表示
- バーがノートに重ならないよう、キャンバスをバーの下に配置
- ホーム画面を「授業をはじめる（左）」と「これまでのノート（右・生徒で絞り込み）」の2ペインに整理
- ノート情報ダイアログは曜日を日付から自動計算（カレンダーからも選択可）
- 色・角丸・余白をテーマ（`ui/theme/Theme.kt`）に集約

### 追加機能
- **授業タイマー**: カウントダウン（1/3/5/10/15分・±1分）とストップウォッチ。終了時に音と画面でお知らせ
- **目隠し**: ノート全体、または選んだ範囲を隠す（v4.1 で変更）
- **ページ一覧**: サムネイルを見て目的のページへジャンプ
- **全画面表示**: バーを隠してノートを広く見せる
- **図形の追加**: 三角形・直角三角形・数直線（XY軸は「図形」の中に統合）
- 授業中は画面が自動で暗くならない
- 編集中の「戻る」操作はアプリ終了ではなくホームへ戻る

### 挙動の修正
- PDF保存先を設定しただけでは書き出しを行わない（書き出しを指示したノートだけを出力）
- ノート情報の変更時に、日付が今日の日付で上書きされないように修正
- 開いているノートを削除したときは、別のノートを表示せずホームへ戻る

## ソース構成（`app/src/main/java/com/example/lecturenote/`）
| ファイル | 役割 |
| --- | --- |
| `ui/LectureNoteApp.kt` | 画面全体の組み立て・ダイアログの出し分け |
| `ui/HomeScreen.kt` | ホーム画面 |
| `ui/EditorBars.kt` | 編集画面の上段バー・ツールバー・選択操作バー |
| `ui/LessonExtras.kt` | タイマー・目隠しシート・ページ一覧 |
| `ui/Dialogs.kt` | ノート情報・設定・確認などのダイアログ |
| `ui/Glyphs.kt` | 消しゴム・投げ縄などの自前アイコン |
| `canvas/LectureCanvasView.kt` | 手書きキャンバス本体 |
| `model/` `data/` `viewmodel/` `util/` | データ・保存・状態管理・PDF出力 |

## ビルド
GitHub Actions（`.github/workflows/android-build.yml`）が `main` への push ごとに APK をビルドし、Release として公開します。
ローカルでは Android SDK を用意して `./gradlew assembleDebug` を実行してください。
