# 家庭教師・授業専用 手書きノートアプリ (LectureNote v3.2)

Xiaomi Pad 7 と専用スタイラスペン向けに構築されたネイティブAndroidノートアプリです。

## v3.2 更新内容
1. 直線の5度刻みスナップ補正（0度、5度、10度...）
2. 投げ縄ツールで選択したオブジェクトの拡大縮小（四隅ハンドル）・回転（上部回転ハンドル）
3. コピー・カット後、別の場所をタップして位置を指定してから「ペースト」ボタンで貼り付け、かつ貼り付け後も選択状態を維持
4. 黒ペン選択時にも一目で分かる二重リング＋白チェックマーク表示
5. GitHub Actions（`.github/workflows/android-build.yml`）によるクラウド自動APKビルド対応
